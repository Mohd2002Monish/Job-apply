# Project Rules & Design Guidelines

## Strict No-Emoji Rule (Universal & Global)
* Never use any raw Unicode emojis or graphical emojis anywhere in the website, mobile app, UI elements, buttons, headers, cards, badges, modal dialogs, toast notifications, or logs.
* Always use clean typography and professional vector/SVG icons from Lucide (`lucide-react`, `lucide-react-native`) or React Icons.

## UI Design Standards
* High-contrast modern dark mode with obsidian glassmorphic card surfaces, subtle 1px frosted borders, electric indigo accents, and emerald success states.
* Responsive tactile micro-interactions with 0.97 scale active states and smooth <250ms ease-out transitions.
